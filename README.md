# Kuesioner PJJ MIS AL MUJTAHIDIN — GitHub Pages + Supabase
1. Buat project Supabase.
2. SQL Editor: jalankan `supabase.sql`.
3. Authentication > Users: buat akun admin email/password.
4. Project Settings > API: salin Project URL dan Publishable/Anon Key ke `assets/config.js`.
5. Upload semua file ke repository GitHub.
6. Settings > Pages > Deploy from branch > main > /(root).
7. URL admin: `/admin/`.
Jangan pernah memasukkan service_role/secret key ke frontend.
